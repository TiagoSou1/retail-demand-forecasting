# Dataset

`retail_price.csv` comes from the [Retail Price Optimization dataset on Kaggle](https://www.kaggle.com/datasets/suddharshan/retail-price-optimization).

- Publisher: Suddharshan S
- License: CC0 Public Domain
- File size: approximately 121 KB
- Shape used in this project: 676 rows and 30 columns
- Granularity: product by month

The file contains product, demand, price, freight, competitor, calendar, and product-attribute fields. It does not contain customer names, contact details, credentials, or employer data.
